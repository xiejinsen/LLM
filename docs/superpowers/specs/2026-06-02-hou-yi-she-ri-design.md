# 后羿射日演示视频设计文档

## 项目概述

- **项目名称**：后羿射日演示视频
- **用途**：教育/科普
- **时长**：30秒以内（900帧 @30fps）
- **分辨率**：1920x1080 (16:9)
- **风格**：中国风/水墨风格
- **技术方案**：纯 CSS/SVG 动画（方案 A）

## 故事结构

| 场景 | 时间 | 内容 | 帧数 |
|------|------|------|------|
| 场景1：开场 | 0-8秒 | 天空出现十个太阳，大地干裂 | 0-240 |
| 场景2：英雄登场 | 8-15秒 | 后羿出现，手持弓箭 | 240-450 |
| 场景3：射日高潮 | 15-25秒 | 后羿射下九个太阳 | 450-750 |
| 场景4：结尾 | 25-30秒 | 天空恢复正常，万物复苏 | 750-900 |

## 视觉设计

### 色彩方案

- **主色调**：黑色、灰色、白色（水墨基调）
- **点缀色**：朱红（印章/英雄服饰）、金色（太阳光芒）
- **背景**：宣纸质感的米白色/淡黄色

### 水墨效果实现

- **墨迹晕染**：SVG filter 的 `feGaussianBlur` 动态变化
- **水波纹**：CSS transform 模拟
- **云雾飘动**：`translateX` + 透明度渐变
- **墨迹纹理**：`feTurbulence` + `feDisplacementMap`

### 字体

- 使用 Google Fonts 的中文书法字体：`Ma Shan Zheng` 或 `ZCOOL KuaiLe`
- 通过 `@remotion/google-fonts` 加载

## 组件结构

```
src/
├── Root.tsx              # 入口，定义 Composition
├── HouYiSheRi.tsx        # 主组件，控制场景切换
├── scenes/
│   ├── OpeningScene.tsx   # 场景1：十日并出
│   ├── HeroScene.tsx      # 场景2：后羿登场
│   ├── ActionScene.tsx    # 场景3：射日
│   └── EndingScene.tsx    # 场景4：万物复苏
├── components/
│   ├── Sun.tsx            # 太阳组件
│   ├── Mountain.tsx       # 山水组件
│   ├── HouYi.tsx          # 后羿人物组件
│   ├── Arrow.tsx          # 箭矢组件
│   └── InkEffect.tsx      # 水墨效果组件
└── styles/
    └── ink.css            # 水墨风格样式
```

### 组件职责

- `HouYiSheRi`：使用 `Sequence` 控制四个场景的切换
- 每个场景组件负责自身的动画和元素
- `InkEffect`：提供水墨滤镜和背景效果
- `Sun`、`Mountain` 等：可复用的视觉元素

## 技术实现

### Remotion 配置

- 分辨率：1920x1080
- 帧率：30fps
- 时长：30秒 = 900帧

### 动画驱动方式

- 所有动画使用 `useCurrentFrame()` + `interpolate()` 或 `spring()`
- 禁止使用 CSS 动画和 Tailwind 动画类
- 时间单位使用秒，乘以 fps 转换为帧数

### 场景切换

- 使用 `<Sequence>` 组件控制四个场景的时序
- 场景间使用淡入淡出过渡

### 依赖项

- `remotion`：核心框架
- `@remotion/cli`：命令行工具
- `@remotion/google-fonts`：字体加载

## 成功标准

1. 视频能在 30 秒内完整播放
2. 水墨风格视觉效果清晰可辨
3. 动画流畅，无卡顿
4. 故事叙事清晰，适合教育科普用途
5. 代码结构清晰，易于维护和扩展

## 风险与备选方案

- **风险**：纯 CSS/SVG 实现复杂水墨效果可能不够理想
- **备选**：如果效果不佳，可切换到方案 B（Lottie 动画）或方案 C（图片序列帧）
- **评估标准**：完成场景 1-2 后评估视觉效果，如不达标及时切换方案
